How TrustLens scores a site

Each test contributes a weight. Failing a test subtracts that weight from a starting score of 100. The final band tells you what to do:

  • Safe (80–100): proceed normally.
  • Caution (50–79): double-check the URL, don't enter passwords unless you're certain.
  • Dangerous (<50): do not enter credentials or click email links.

Accuracy: on PhishTank-validated phishing, TrustLens catches ~85–88% when all threat feeds (GSB, PhishTank, URLhaus) are active. Lower without them. Heuristic-only — not a substitute for paid enterprise anti-phishing.

Tests run

  • Google Safe Browsing — Google's malware/phishing list. (needs API key)
  • DNSSEC (AD flag) — chain validated by resolver.
  • Cross-Resolver Consistency — Google vs Cloudflare agree.
  • Homoglyph / Punycode — xn-- or non-ASCII lookalikes.
  • Domain Age — RDAP registration date.
  • Registrar Reputation — known-abused vs known-trusted registrars.
  • SSL Certificate Age — first cert seen in CT logs.
  • Typosquat / Spelling Trick — Levenshtein distance to common brands.
  • Favicon Brand Match — visual clone detection via pHash.
  • Email Authentication — MX + SPF + DMARC presence.
  • HTTPS Enabled — current scheme.
  • Form Action Audit — password form posting off-origin.
  • iFrame Clickjack Scan — login framed by third party.
  • Form Submit Watcher — warns before credential submit.
